# Registro de Uso de IA Generativa

## Avaliação A1 - Módulo de Produtos

O uso de IA durante o desenvolvimento da avaliação A1 foi pontual, servindo como ferramenta de apoio e consulta para partes específicas:

- Apoio na estrutura inicial dos records DTOs e anotações do Swagger (@Schema).
- Consulta de boas práticas para a validação de regras de negócio (rejeição de estoque negativo retornando HTTP 422 com Problem Details RFC 7807).
- Revisão da estrutura dos testes unitários seguindo o padrão AAA (Arrange, Act, Assert).

Todo o código foi revisado, testado e compreendido por mim, dominando integralmente a arquitetura em camadas, as convenções de chave primária com prefixo id_, a criação da tabela via Flyway, o CRUD completo e a semântica HTTP.
